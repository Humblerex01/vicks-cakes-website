# 🍰 Vick’s Cakes & Pastries

Welcome to **Vick’s Cakes & Pastries** — a modern bakery website that showcases our delicious handcrafted cakes, pastries, and special treats made with love.  
This website was built to provide customers with an elegant, interactive experience where they can explore our menu, learn about our story, and place their orders easily.

---

## ✨ Features

- 🎨 Clean and responsive design using **Next.js + Tailwind CSS**
- 📱 Fully mobile-friendly layout
- 🎥 Hero section with background video for visual appeal
- 🍪 Beautifully structured **Menu Page** with cake categories
- 💬 WhatsApp-integrated contact form for instant messaging
- 👨‍🍳 About page highlighting the baker’s journey
- 🚀 Fast deployment and optimization on **Vercel**
- 📜 Dynamic navigation bar and footer on all pages

---

## 🧰 Built With

- [Next.js 14](https://nextjs.org/) — React framework for production
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first styling
- [Framer Motion](https://www.framer.com/motion/) — Smooth animations
- [Lucide Icons](https://lucide.dev/) — Beautiful icon set
- [Vercel](https://vercel.com/) — Hosting and deployment
